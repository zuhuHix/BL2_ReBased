## 2026-11-11: PR #215 review 1: stored paths must stay in this checkout; refresh keeps a backup and refuses links; the ambient jobs too

AI-assisted (Claude Opus 5.5). Follows the entry above (lane-data-hygiene); same files plus `tools/ambient_npc_assets.py` and `tools/seed_ambient_npc_assets.ps1`.

- **Paths in jobs (`tools/repo_paths.py`).** A relative value is normalised and refused when it leaves the repository root (`../runner-z55/local/slice`). A rooted value (`\local\x`) or a drive-relative one (`C:foo`) is refused too. Any path, input or output, whose real location (junctions followed) is inside another checkout of this repository is refused. That covers a `local/` junctioned into another worktree and an absolute input that still exists in another worktree; the entry above accepted the latter. "Another checkout" uses the same test as the guard: the nearest folder upwards with a `.git` entry and `host/ue5/OpenWillow/OpenWillow.uproject` that is not this root. An absolute input outside every checkout (the game install, an export folder) is still used when it exists. A `local/` junctioned to a plain data folder is allowed.
- **Refresh (`tools/provision_worktree_assets.ps1 -RefreshStale`).** An existing target that is a symlink or junction is refused before it is hashed or replaced. The old file is moved to `local/worktree-refresh-backup/<UTC time>/<path>` (seed mode: `<seed>/worktree-refresh-backup/...`) before the new copy is written. Both steps are printed as they happen, so a failure part-way still shows what was done. The backup folder is an excluded name, so it is never copied. With a junctioned `local/` a refresh that would replace a file is refused, since the backup would land in the shared root.
- **Guard and wiring (`tools/checkout_guard.ps1`).** The checkouts are compared by physical path (`GetFinalPathNameByHandle`), so a current directory that reaches this checkout through a junction is allowed. The resolve step is one shared function, `Resolve-OwEditorJob`, used by the three launchers.
- **Ambient NPCs.** `tools/ambient_npc_assets.py` writes `editor_job.json` and `attach_job.json` with repo-relative paths. `tools/seed_ambient_npc_assets.ps1` runs the guard and hands the editor the resolved copies.
- **Verified (automated):** `tests/editor_inputs_test.py` covers the three escaping shapes, an input still present in another checkout, a junction into another checkout and into a plain data folder, the guard through a junction to this checkout, and the shared resolve function with a good and a stale job. `tests/provision_worktree_test.py` covers the backup and its message and that backups and resolved jobs are never copied.
