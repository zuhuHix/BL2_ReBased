## 2026-11-12: Audiokinetic's public Wwise SDK documentation is a format reference for the game's sound banks (audio)

AI-assisted (Claude Code). Maintainer decision of 2026-11-12. Provenance: `THIRD_PARTY.md`, "Format references (read, not copied)". No tool, parser or host behaviour changes.

- **Decision.** The public Wwise SDK documentation may be read to learn the sound-bank structure fields for the bank version the game uses (62, `docs/verification/SLICE_AUDIO_CHAIN.md`). It is read, not copied: no SDK download, no SDK headers or code, no copied text, no account. Only the site's home page is linked, as its terms allow.
- **How it is read.** Pages of that site are read by a person in a browser only: no agent or tool fetches them, and nothing is saved. So the reference is for the maintainer's own reading, and notes from it reach the project in the maintainer's own words.
- **Seen on 2026-11-12.** The documentation opened without an account. Its version list showed no version before Wwise 2021.1.14, and two older-version addresses led to the current documentation, so it is assumed, not checked, that the public library does not cover bank version 62. The approval covers the public documentation only. The site's Terms of Use, as read once that day, allow copying a document only for internal reference or personal use and forbid automatic copying of pages; that summary was not re-checked and may be incomplete. The version check was made by fetching six documentation and terms pages with a script before the terms had been read; the copies sat in a scratch folder outside the repository and were deleted the same day. After that, during review, a tool tried once more to fetch the terms page; the site refused it, so nothing was received. The browser-only rule above applies from this decision on.
- **Not checked:** which Wwise release wrote bank version 62; whether the public pages describe the bank's fields at all. The bank layouts the project uses stay as recorded, fitted on the banks and checked over the install.
