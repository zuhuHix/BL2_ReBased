## 2026-11-09: A magazine below one shot's cost reloads, on the test driver as on the player's trigger (shoot-stall lane)

AI-assisted (Claude Haiku 5.5). The open item from the magazine-fixture entry above: `ShootAt` stalled when the magazine held more than zero but less than one shot's cost (a two-round shot, the lent pistol, with one round left). `FireOnce` refuses that shot, and `ShootAt` reloaded only from an empty magazine, so the step neither fired nor reloaded until its timeout. The player's own trigger already reloaded in that case: `ConsumeShot` refuses the shot and `AOpenWillowWalker::Tick` then calls `StartReload`, which needs only a magazine that is not full and a pool with ammo. The fix makes the test driver follow the same rule.

- **Rule (host choice).** A magazine below one shot's cost, zero included, is a reload: the trigger reloads, and no partial shot goes out. Added as `UOpenWillowInventory::MagazineBelowShot` (false for a gun that costs no ammo, so an infinite-ammo gun never takes this path). `ShootAt` and the magazine fixture's post-link reload (`HoldForFixtureReload`) both use it, so the test driver and the player agree.
- **Native reading (UNVERIFIED in game).** `docs/verification/NATIVE_WEAPON_TRIGGER_AMMO.md` section 3, step 3, reads that a press with a non-empty clip enters firing, and section 2 of the per-shot rules clamps a clip below the cost to 0. Read together, the game may fire a partial shot instead of reloading. The host does not do that today and this change does not decide it. The reload is a host choice that matches the player path already in the code, not a recorded game behaviour; whether the real game fires a partial shot or reloads stays UNVERIFIED.
- **Side effect.** `ShootAt` no longer tries the reserve refill for a gun that costs no ammo with an empty magazine. That refill was a fixture step, and the gun never needed a reload.
- **Fixture comment.** The `-owslicegatemag` clamp (magazine at least one shot's cost) is kept, because it still makes the first shot empty the magazine. Its comment no longer claims that a smaller magazine stalls.
- **Verified (automated):** none run here. The inventory self-test has new rows for the rule (a one-round magazine under a two-round shot reloads and does not fire; an empty magazine reloads; two rounds fire; a gun with no ammo cost never takes the rule). They run in the in-engine self-test, not in ctest.
- **Not verified:** in engine. The firing suite and the range suite have not run with this change. Whether the lent pistol now reloads and completes the ShootDummy step is unseen.
- **Record:** no game-derived data in this entry; the only input is the existing native-behaviour note above.
