# Suite map for BL2_ReBased: the heavy local suites, what each covers and how each runs. Tracked since 2026-11-12; before that
# it lived in the hub's ignored local/hub/ folder. Read by tools/suites_due.py (which suites are due on a commit) and
# tools/run_suites.ps1 (runs them); checked by tools/suite_map_lint.py (CTest suite-map-tracked). The format and the rules
# are in docs/TOOLING.md, "Heavy suites: the suite map". Changing a line's paths or command makes that suite due again;
# comments and #pass lines are not part of any key, but this file and tools/suites_switch_only.txt are read by the unit
# suite's CTest entry suite-map-tracked, so any edit here makes unit (and slice_gate, which covers ".") due.
# The minutes were measured on the main desktop (editor log spans of earlier runner logs plus about a minute of start, lock
# and build); lines marked "are a guess" have no log behind them.
#
# How the lists were built:
# - Every in-engine suite has the C++ core (CMakeLists.txt src/ third_party/: the UE module links build/Release/ow-core.lib),
#   the host project (host/ue5/OpenWillow/: Source, Config, uproject; Content is untracked), tools/ue_lock.ps1, its script,
#   checker and dot-sourced helpers, tools/hud_overlay/ when it serves pages, the tools it runs during the run, and the
#   generators of the local files it requires, with their tools/ imports (computed from import lines, not read by hand).
# - slice_gate is the smoke suite on "." and the only line that covers the Sanctuary scene/import pipeline
#   (prepare_level.py and friends, run_ue_level.ps1, host/ue5/*.py) and the host-read manifests no script names.
# - A generator change only matters after its local data is regenerated: rerunning on the copied data proves nothing.
#   After regenerating ignored data, delete the ledger lines of the suites whose "# data:" names it.
#
# Before run_suites.ps1, on the test worktree (the driver starts no build):
#   cmake --build build --config Release   (unit does it too, but only when unit is due)
#   the UE module: <OPENWILLOW_UE>\Engine\Build\BatchFiles\Build.bat OpenWillowEditor Win64 Development -Project=<worktree>\host\ue5\OpenWillow\OpenWillow.uproject -WaitMutex
#   Only slice_gate*, range, weapon_firing, vendors and interactives build the UE module themselves; none rebuilds ow-core.lib.
#   Env: OPENWILLOW_BL2 = the installed game; OPENWILLOW_UE = the Unreal folder (the scripts fall back to their own default).
# Commands run each script with -File and end in "exit $LASTEXITCODE": under -Command a script's exit 2 or 3 would
# otherwise come back as 1 (or 0 after a passing last line).
# Each suite line has a "#pass <name> | <must match> | <must not match>" line under it, which run_suites.ps1 reads.
#
