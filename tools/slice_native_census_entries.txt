# Entry list for tools/slice_native_census.py: the script the Fire mission ("Rock, Paper, Genocide: Fire Weapons!", giver
# Marcus) reaches on the player controller, the mission tracker's script side, the giver's director functions, the
# accept/turn-in screen, mission population and the Behavior and Kismet classes of the mission's data. Names only; the
# format is documented in src/census.hpp. Every entry runs on objects built from class defaults, with each native that has
# no implementation as a logged zero-result stub, so many entries stop short on a None or zero result (reported, not hidden).
# Entries run in file order on the same objects. Struct-typed arguments (mission data, rewards) are left at their zero value.
